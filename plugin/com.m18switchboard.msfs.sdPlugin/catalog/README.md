# Browse catalogs

`simvars.json` and `events.json` feed the editor's Browse dialogs. They are generated by
`scripts/build-catalog.py` from the MSFS 2024 SDK documentation (docs.flightsimulator.com,
retrieved 2026-10-29): every simvar, environment variable and key event listed there, with the
SDK's descriptions, units and event parameters. Hand-picked common entries (`common-*.json`, edit
these by hand) come first, starred. Rerun the script after editing a common list or when the SDK
docs change. Third-party aircraft L:vars are not in the SDK and are not listed.
